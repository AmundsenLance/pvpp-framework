# PV-PP Framework

This repository contains the canonical public explainer pages for the **Productive Value–Productive Power (PV-PP) framework**.

The PV-PP framework is a non-scalar approach to understanding human interaction, decision making, behavior, and viability. It distinguishes between:

- **Productive Value (PV)** — what is transferred, created, preserved, lost, or realized through interaction
- **Productive Power (PP)** — the structured capacity to generate, receive, preserve, protect, apply, or recover that value
- **Perceived Productive Power (PPP)** — the interpreted or projected estimate of capability, which may diverge from actual capability

## Purpose of this repository

This repo serves as a **canonical public entry point** for the framework. Its purpose is to give readers and search systems a stable, concise explanation of:

- what the PV-PP framework is
- what makes it non-scalar
- what kinds of problems it addresses
- how the framework looks in a concrete worked example
- how the mature framework grew out of the original model

## Current public themes

The framework currently appears publicly in connection with:

- human interaction and exchange
- value versus capacity
- information quality and misperception
- viability and recovery
- non-scalar decision structure
- addiction and recovery analysis
- AI agent governance and runtime viability

## Status

The PV-PP framework is an active research project rather than a finished mainstream doctrine. Public materials currently include introductory essays, GitHub-hosted pages, Substack posts, demos, and video explainers.
